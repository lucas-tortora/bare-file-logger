# bare-file-logger

File system logger for Bare.

## Usage

```js
const FileLog = require('bare-file-logger')

const log = new FileLog('my-logs.txt')

log.info('Hello %s', 'world!')
```

## API

See the [`bare-file-logger` reference](https://docs.pears.com/reference/bare/modules/bare-file-logger).
